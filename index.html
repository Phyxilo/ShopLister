Shop Lister

A small, personal tool for managing my own shop.

About me

I'm Emin Yuksel, an individual developer and seller based in Turkey. I run a small shop on Etsy and build my own tools to help me look after it.

What the app does

Shop Lister is a personal tool I use to manage my own Etsy shop. It connects only through the official Etsy API.

  • Market research: it reads public listing and shop data so I can understand pricing, trends, and what buyers are looking for.
  • Managing my own listings: once I authorize it for my shop, it will create and update listings in my own shop.

What this app is not

  • It is not a public or commercial service.
  • It is not offered to other sellers and does not act on anyone else's shop.
  • It uses only the official Etsy API and no other method of accessing Etsy.

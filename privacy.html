Privacy Policy

Last updated: September 23, 2026

Shop Lister is a personal tool operated by Emin Yuksel, an individual developer and seller based in Turkey. It is used only to manage my own Etsy shop. This page explains what data the app accesses and how it is handled.

Data the app accesses

The app accesses data only through the official Etsy API:

  • Public data: publicly available listing and shop information, used for market research.
  • My own shop's data: once I authorize the app for my own shop, it can access my shop's listings, orders, and shop statistics.

The app does not access any other seller's private data.

Where data is stored

Data retrieved by the app is stored locally on my own computer. It is not uploaded to any external server or cloud service operated by the app.

Sharing and selling

No data is sold, rented, or shared with third parties. The app does not use advertising, analytics, or tracking of any kind.

Buyer information

Orders from my own shop may include buyer information such as names and shipping addresses. This information is used only to run my shop, for example to fulfil and ship orders and to provide customer support. It is not used for any other purpose.

This website

This website is a static page hosted on GitHub Pages. It does not use cookies, analytics, or trackers, and it does not load any external resources. GitHub may process basic technical information (such as IP addresses) as part of hosting; see GitHub's own privacy statement for details.

Questions and deletion requests

If you have questions about this policy, or would like data related to you to be deleted, please email me at eminyuksel97@gmail.com. I will respond as soon as I can.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new "last updated" date.

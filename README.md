# Shop Lister – Homepage

This repository hosts the public homepage for **Shop Lister**, a personal tool
that Emin Yuksel uses to manage a personal shop through the official Etsy API.

The site is served with GitHub Pages and has two pages:

- `index.html` – what the app is and how to get in touch
- `privacy.html` – privacy policy

It is plain HTML and CSS (`style.css`), with no JavaScript, build step, or
external resources.

but is not endorsed or certified by Etsy, Inc.
